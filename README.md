# Easy Conifer

Процедурный генератор деревьев и кустов для Blender 5.x на Geometry Nodes: ели, пихта, берёза, тополь, ива, клён, ясень, липа; кизильник, пузыреплодник, лещина, клён ясенелистный.
Работает в паре с [Easy Tree](https://github.com/jacobcjohnston/Easy-Tree):
панель лежит в той же вкладке **Easy Tree** боковой панели 3D-вида. Если
Easy Tree установлен, по умолчанию берётся его материал коры.

Лицензия: GPL-3.0-or-later.

## Установка

`Edit → Preferences → Get Extensions → ▾ → Install from Disk…` → выбрать
`easy_conifer-0.9.0.zip`. Проверено на Blender 5.2.

## Управление через MCP и скрипты

С версии 0.9.0 аддон публикует API для Python-скриптов и ИИ-агентов, работающих через Blender MCP:

```python
import bpy, json
ec = bpy.app.driver_namespace["easy_conifer_api"]
ec.add_row("TILIA_CORDATA", (0, 0), (60, 0), spacing=8)                       # аллея лип
ec.add_hedge("HEDGE_COTONEASTER", (0, -4), (60, -4), height=0.9, depth=0.7)   # изгородь одним объектом
print(json.dumps(ec.scene_info(with_tris=True), ensure_ascii=False))
```

Справочник функций и порядок работы для агента — [MCP.md](MCP.md).

## Как пользоваться

1. 3D-вид → `N` → вкладка **Easy Tree** → блок **Easy Conifer**.
2. Выбрать пресет (разделы «Хвойные», «Лиственные», «Кусты», «Стриженые кусты»; для стриженых — ещё и форму) и нажать **Add Tree**. Дерево появится в 3D-курсоре.
3. Основные ползунки есть прямо в панели. Все остальные параметры находятся
   в модификаторе (вкладка Modifier Properties), они разбиты на группы.
4. **Apply Preset** перезаписывает параметры выделенных деревьев пресетом
   (сид и материалы сохраняются). **New Seed** даёт новый вариант дерева.

## Как устроено

Группа нод **Conifer Generator** (её создаёт скрипт `nodes_builder.py`):

- **ствол** — одна вертикальная кривая до макушки (моноподиальный рост),
  с утолщением у корня;
- **мутовки** — ярусы по *Branches per Whorl* ветвей через *Whorl Spacing*,
  плюс короткие межмутовочные ветви;
- **ветви 1-го порядка** — длина задаётся профилем кроны (*Branch Length*,
  *Crown Shape*, *Skirt*), угол меняется от *Angle Bottom* к *Angle Top*,
  провисание регулирует *Droop*, подъём кончика — *Tip Upturn*;
- **веточки 2-го порядка** — поочерёдно влево и вправо в плоскости ветки,
  *Twig Hang* опускает их вниз (у обыкновенной ели получается «гребёнка»).
  Геометрии у них нет: каждая веточка — **кросбокс** из двух квадов
  (горизонтальный и вертикальный, высоту вертикального задаёт *Flatness*);
- **мельчайшие веточки (спреи)** вдоль наружной части ветвей и у макушки —
  **один полигон** (*Spray Size*, *Spray Spacing*);
- **шишки** (инстансы) и **ветер** (сдвиг всей геометрии по времени сцены).

## Лиственные (Broadleaf Generator)

Группа нод **Broadleaf Generator** (`broadleaf_builder.py`) — общая для всех
лиственных; вид задают пресет, атлас листьев и кора.

- **ствол** — наклон (*Lean*), плавная волна (*Trunk Wiggle*), утолщение у
  корня; *Leader Height* — где ствол кончается: 0.97 — до макушки (берёза,
  тополь пирамидальный), 0.45–0.6 — крона расходится на несколько стволов
  (клён, ива, чёрный тополь);
- **скелетные ветви** — по спирали или супротивными парами накрест
  (*Opposite* — клён, ясень). Длина каждой ветви считается до **эллипса
  кроны**: *Crown Width* — его ширина к высоте дерева, *Branch Length* —
  доля этого вылета. Ветви поднимаются, загибаются вниз (*Arch*) и могут
  поднимать концы (*Tip Upturn*);
- **ветви 2-го порядка** — геометрия, поочерёдно в стороны, провисают;
- **облиственные побеги** — кривые от направления ветви к земле (*Weeping*);
  вдоль них цепочкой стоят кросбоксы через *Card Length*, поэтому листья
  остаются в натуральную величину даже на 3-метровых занавесях ивы
  (тайлы 0, 1); *Twig Wood* добавляет под карточки тонкую геометрию побега;
- **розетки листьев** — одиночные полигоны (тайлы 2, 3);
- **кора** — у берёзы белая рябая (ствол и скелетные ветви) и тёмные ветви
  2-го порядка; у остальных — параметрический шейдер на ячейках Voronoi:
  длинные пластины и глубокие борозды (тополь, ива), ромбическая сетка
  (ясень), мелкие гребни (клён, липа); тонкие ветви — гладкая молодая кора
  (атрибуты `bark_r`, `bark_level`).

Листья в атласах (`birch_twig.py`, `broadleaf_twig.py`) — полигональные:
сеточные (берёза, тополь, ива, листочки ясеня) и полярные (пальчато-лопастный
клён, сердцевидная липа); сложный перистый лист ясеня собран из листочков
на рахисе. *Leaf Color* перекрашивает только листья — так сделаны осенние
пресеты.

Полигонаж (тыс. треугольников): ясень — ~30, берёза 17 м — ~33, ветла — ~65,
клён — ~80, липа — ~82, тополь пирамидальный 25 м — ~95, чёрный — ~101,
ива плакучая — ~139 (занавеси из цепочек карточек). Снижается через
*Twig Density*, *Spray Spacing* и *Secondary Density*.

## Кусты и многоствольность

*Stems* — число стеблей от земли (1 — дерево), *Stem Spread* — их наклон
наружу. Ветви распределяются по стеблям и направлены в основном наружу,
вылет до контура кроны пересчитывается с учётом смещения стебля; у кустов
облиственна вся верхняя половина каждого стебля. Полигонаж кустов —
14–26 тыс. треугольников.

## Цвет листвы

Цвет каждой карточки считается в генераторе (атрибут `needle_color`),
материал перекрашивает им только листья, не стебли:

- *Inner Shade* — листва у ствола и в глубине кроны темнее, у поверхности
  кроны светлее (средняя яркость сохраняется);
- *Top Light* — верх кроны светлее, низ темнее;
- *Edge Color* / *Edge Color Amount* — подкраска поверхности кроны (молодая
  жёлто-зелёная листва, осенние края);
- *Hue Variation* и *Color Variation* — случайный разброс оттенка и яркости
  по карточкам;
- *Leaf Gloss* — лаковый слой (Coat) — глянцевые листья тополя, кизильника;
- *Leaf Sheen* — бархатистость (Sheen) — опушённые листья лещины, ветлы.

Gloss и Sheen передаются в материал атрибутами `leaf_coat` / `leaf_sheen`,
поэтому настраиваются на каждом дереве отдельно, а материал общий.

## Стриженые кусты (Clipped Shrub Generator)

Для городской визуализации — живые изгороди и фигурно стриженые кусты.
Отдельная группа нод `hedge_builder.py`, бюджет 2–4 тыс. треугольников на куст:
шар 1,2 м ~1,8 тыс., трапеция ~2,5 тыс., куб 2 × 0,9 × 1 м ~3,7 тыс., естественный
1,8 × 1,6 × 1,5 м ~3,2 тыс.; плотность пропорциональна площади поверхности,
поэтому длинная изгородь — ~1,8 тыс. на погонный метр.

- **форма** — суперэллипсоид: *Roundness* 0 — куб с острыми рёбрами,
  1 — шар/эллипсоид; *Top Taper* < 1 — трапеция; *Bottom Cut* — подрезка
  снизу; *Unevenness* — неровный контур естественного куста; размеры
  *Width* × *Depth* × *Height* (длинная изгородь — большая *Width*);
- **листва только снаружи, в три слоя**: открытый наружный слой куртин с
  просветами (*Surface Density*, *Card Size*, *Card Tilt*, *Surface Roughness* —
  насколько карточки выступают: мало — чёткая стрижка), сквозь него виден
  средний слой и тёмный глубокий (*Inner Layer* — их плотность, *Foliage Depth* —
  толщина листового слоя в метрах: слои сдвинуты внутрь по нормали, поэтому
  глубина одинакова и у шара, и у изгороди длиной 20 м); торчащие побеги
  «ворс» (*Fuzz Density*, *Fuzz Size*);
- **внутри почти без листвы**: несколько стеблей сечением 4 полигона
  (*Stems per Metre*) и крест-плоскости с запечёнными голыми V-развилками
  после стрижки (*Inner Branch Density*), просвечивающие в просветах;
- цвет — как у лиственных (*Inner Shade*, *Top Light*, *Edge Color*, *Leaf Gloss*).

**Формы** (выбираются при добавлении и кнопкой **Apply Form** для выделенных
кустов, с опцией сохранить размеры): Шар, Куб, Трапеция, Естественный.

**Виды**: кизильник блестящий, пузыреплодник (зелёный, 'Diabolo', 'Luteus').
Для них отдельный атлас `<вид>_hedge_*`: побег для «ворса», голые развилки,
две плотные куртины листьев; запекается той же кнопкой Bake.

## Текстуры веточек

На карточках — запечённые высокополигональные веточки с настоящими
иголками (`twig_baker.py`). Атлас 2×2 на вид (ель, пихта и все лиственные):

| тайл | что | где используется |
|---|---|---|
| 0, 1 | веточка 2-го порядка с боковыми побегами | кросбоксы веточек |
| 2, 3 | маленький спрей | однополигональные карточки на ветвях |

Карты (PNG): `*_albedo` (цвет + alpha), `*_normal` (tangent space, OpenGL),
`*_mask` (R — AO, G — маска иголок/листьев, B — толщина для просвечивания,
A — случайный номер листа).

**Блики и рельеф (0.8).** Нормали запекаются с сильным разбросом наклона
листьев, карта нормалей подключена и к основному слою, и к лаку (Coat Normal) —
блик дробится на отдельные листья, а не ложится плоским пятном на карточку.
По номеру листа (mask A) каждый лист получает свою шероховатость, силу лака
и яркость; древесина матовая (0,85). Карточки, повёрнутые к камере ребром,
плавно растворяются — нет «размазанных» листьев на силуэте.
В аддоне лежат готовые атласы 2048 для всех видов.

**Перепечь у себя:** панель → *Twig Textures* → вид, разрешение, сид,
плотность иголок → **Bake Twig Textures** (около минуты на вид при 2048,
Cycles на CPU). Новые атласы сохраняются в папку данных расширения и сразу
подхватываются материалами; стрелка рядом возвращает поставочные.

Цвет хвои перекрашивает *Needle Color* (материал умножает иголки на
отношение к цвету, с которым они запекались), стебли остаются коричневыми.

### Полигонаж (ель обыкновенная 14 м)

| | 0.1 (иголки-геометрия) | 0.2 (wave-ленты) | 0.3 (атлас + кросбоксы) |
|---|---|---|---|
| треугольников | ~9 000 000 | ~172 000 | ~36 000 |

Самая тяжёлая из пресетов (старая ель 26 м) — ~45 тыс., молодая ёлочка — ~13 тыс.

### Cycles: прозрачные переотражения

Карточки перекрываются, и при стандартном лимите *Transparent Max Bounces* = 8
глубина кроны рендерится чёрными квадратами. **Add Conifer** поднимает лимит
сцены до 32, если он ниже (и пишет об этом в статус-строке).

### Экспорт

После *Apply* модификатора дерево — лёгкий меш с UV на атлас. Для FBX/OBJ
возьмите PNG из папки `textures` (или перепечённые) и подключите в целевой
программе как Base Color + Alpha (alpha clip/blend), Normal (OpenGL).

## После обновления аддона

Кнопка **Rebuild Node Group** пересоздаёт группу нод и переносит значения
параметров на все существующие ели. Ручные правки внутри группы при этом
теряются.

## Заметка про Easy Tree на Blender 5.2

В Blender 5.2 значения входов модификатора больше нельзя записывать как
`mod["Socket_N"]`, теперь это `mod.properties.inputs.Socket_N.value`.
Поэтому кнопка Add Tree в самом Easy Tree 1.0.0 на 5.2 падает с ошибкой.
Easy Conifer поддерживает оба варианта (`modifier_io.py`).

## Первоисточник

Easy Conifer сделан как компаньон к **Easy Tree** — генератору деревьев на Geometry Nodes
(автор Jacob Johnston, GPL-3.0-or-later): <https://github.com/jacobcjohnston/Easy-Tree>.
От Easy Tree взяты идея и место в интерфейсе: вкладка **Easy Tree** боковой панели. Если Easy Tree
установлен, используется его материал коры. Код Easy Tree в этот репозиторий не входит. Поэтому
Easy Conifer распространяется под той же лицензией GPL-3.0-or-later (см. `LICENSE`).
